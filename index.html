Mechanism

Redundancy is local. Its treatment should be adaptive.

Neighboring pathology patches can repeat morphology, but repetition is not uniformly harmful. GatedSRP estimates a local redundancy direction and learns a signed, token-specific correction after attention.

01

Estimate

Gather the valid 3x3 spatial neighbors of each patch and average their detached value vectors.

02

Project

Project the patch attention update onto the normalized local redundancy direction.

03

Gate

Predict a bounded signed coefficient from token and head diagnostics, initialized at identity.

Local direction r̂ᵢ = normalize(meanj∈N(i) vⱼ)
→
Signed correction zᵢ = yᵢ − βᵢ ⟨yᵢ, r̂ᵢ⟩ r̂ᵢ
→
Bounded gate βᵢ = δ tanh(gᵢ)

Learned behavior

A signed gate, not a fixed suppression rule

Most token-level means lie between zero and one, but the model can preserve the original update, apply weak negative correction, or move beyond full projection when the context supports it.

Reproduce

From raw slides to comparable metrics

Paths are environment variables, so existing slide and embedding stores can stay where they are. Public labels, exact run matrices, and result collectors are included.

  1. 1

    Install

    Choose Conda, venv, or uv and install the CUDA build of PyTorch for your system.

  2. 2

    Prepare data

    Download the public slides or stage an existing collection, then point the path variables at it.

  3. 3

    Extract embeddings

    Run the AtlasPatch launcher to create coordinate-aligned UNI-v2 H5 files.

  4. 4

    Run and collect

    Select manifest rows, train five seeds, and compare the collected TSVs with the bundled values.

Quick start

  --where dataset=cam17 --where method=gated_post_attention \
  --where seed=42

Integrate

Add one patch-token correction

Insert GatedSRP after a patch-token attention update and before the residual path. CLS tokens, positional encoding, attention implementation, and task heads remain unchanged.

  • Works with variable-length bags and fixed patch grids
  • Supports streaming neighborhood means and chunked correction
  • Includes Nyström, dense MHSA, SPAN, and LongNet integrations
  • Starts as an exact identity through zero gate initialization
Read the integration contract
Post-attention hook 
from slide_level_srp.src.srp_correction import (
    PatchSRPCorrection,
)

self.srp = PatchSRPCorrection(
    dim,
    hidden_dim=32,
    delta_scale=2.0,
    correction_chunk_size=8192,
)

update = self.attn(x)
patch_update = self.srp(
    update[:, 1:],
    neighbor_index,
    neighbor_mask,
    neighbor_weight=neighbor_weight,
)
update = torch.cat(
    [update[:, :1], patch_update], dim=1
)
return x + update
