# Paper Tables

This directory contains paper-facing reference TSVs from the audited internal run package.

| File | Purpose |
|---|---|
| `classification_main_table.tsv` | Main classification table with PANDA taken from the TransMIL rerun package. |
| `classification_per_run_metrics.tsv` | Per-seed classification metrics for the 100 public manifest rows. |
| `tcga_survival_main_table.tsv` | Main TCGA survival case-level C-index table. |
| `tcga_survival_per_run_metrics.tsv` | Per-seed TCGA survival metrics for the 100 public manifest rows. |
| `tcga_gated_srp_reported_configs.tsv` | Cohort-specific Gated SRP configs used for the reported TCGA survival row. |
